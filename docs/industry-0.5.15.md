# 行业词库与编程输入

数萌AI服务器 (winintel) / Alex YANG · GPL-3.0-or-later

Windows 0.5.15 / Android 0.1.9 本地验证版本。

在“设置 → 键盘输入 → 行业词库”选择编程、AI、医疗、金融、法律、教育、制造或电商。手机从输入法工具箱打开“行业词库”，进入设置选择。默认通用词库，个人中文选词保存在本机，切行业和升级后继续优先。

Windows 编程行业中，英文状态支持 Python、PyTorch、JSON.parse、std::vector、user_id 等规范补全。输入前缀后用上下键选候选，Tab 上屏；空格和 Enter 保留原始标识符。开启代码输入保护后，常见代码编辑器自动使用英文；Shift 手动切中文后，自动英文不会覆盖手动选择。保留 Ctrl/Alt/Win 编辑器快捷键。未知标识符原样输入。

Android 在英文键盘展示行业候选，点击候选上屏；数字和符号键保留现有手机键盘行为。密码输入不使用候选或记词。不根据手机宿主应用自动推断行业。

行业包来自已随项目公开分发的词库和人工校验种子，中文全拼与简拼共用数据，手机同时支持九宫格。术语包独立于基础词库；个人记词不是行业之间隔离的用户档案，目的是让个人习惯在任何行业都继续有效。英文标识符目前不参与个人中文学习。

扩展测试冻结 1,295 例拼音和 200 例代码补全，覆盖原 200 例、八行业全拼/简拼、日常、姓名、办公整句、相邻错键、代码精确/前缀/大小写。用例由开发者选择，不是独立盲测。所有失败保留，旧版和新版使用同一份冻结输入；搜狗仅对实采候选覆盖的样本做同集比较。语音识别本轮未更改，不能从拼音结果推断语音提升。
