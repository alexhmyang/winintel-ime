# Windows 0.5.8：英文补全、中英文热词与每日新闻

旧版本的英文模式直接把字母传给软件，没有经过候选引擎，因此没有英文联想。0.5.8 加入独立的本地英文前缀词库，包含 22,437 项常用词、缩写及技术名称；不调用云端模型。

| 操作 | 结果 |
|---|---|
| Shift 切到 EN，输入 `hel`，按 Tab | 补全为 `hello` |
| 输入 `deepse`，按 Tab | 补全为 `DeepSeek` |
| 上下方向键，再按 Tab，或直接点击候选 | 选择其他补全词 |
| 输入 `hel`，按空格 | 输入 `hel `，保留原词和空格 |
| Shift + 字母 / 全大写字母 | 保留首字母大写 / 全大写格式 |
| 数字、标点、回车、Ctrl 快捷键 | 先上屏原词，再交给当前软件 |
| 左右方向键、Home、End、Backspace、Delete | 编辑待补全字母 |
| 单独按下并松开 Shift | 保留原词，切换中英文 |

英文候选用圆点标记，底部提示“↑ ↓ 选择 · Tab 补全 · 空格原词”；数字不作为英文选词键。完整已知单词优先于更长的补全；需要其他词时用上下方向键选择。本版实现前缀补全，不是上下文长句生成。

中英文热词包日期为 **2026-11-26**，由 winintel AI 编辑精选。中文词条涵盖智能体、具身智能、多模态、端侧推理、新质生产力、低空经济、情绪价值等；英文包括 DeepSeek、ChatGPT、Qwen、NVLink、InfiniBand、vLLM、agentic、multimodal、reasoning、quantization 等。中文热词同时支持完整拼音和简拼，个人词库和学习记录继续优先。英文基础词表版本为 2026-10-01；精选热词不代表互联网实时热度排行。

右键托盘 → **每日新闻与热词**。默认中文源为 IT之家，英文源为 NPR 世界新闻。已实际下载 2026-11-26 发布的新闻，列表按发布日期倒序，只保存标题、发布日期、来源与原文链接；双击打开原文。来源可改成其他 HTTPS RSS / Atom，或者关闭某个源。

实时更新默认开启，每 **5 分钟**刷新一次，可设置为 1–60 分钟；软件关闭期间不会下载。面板可关闭自动刷新，也可随时点击立即刷新。自有新闻接口填写 HTTPS `/v1/news`，本机开发允许 `http://127.0.0.1:8788/v1/news`。开启回退后，自有接口失败时使用免费 RSS。失败保留缓存；文章发布日期、下载时间和错误分别显示。来源超过 48 小时无新条目会标记过期。

热词更新地址可填写你自有后台的 `https://你的域名/v1/hotwords`。现有开源服务端已提供该接口，本机开发地址为 `http://127.0.0.1:8787/v1/hotwords`；维护 `service/hotwords.json` 即可更新中英文词包。未配置远端地址时使用本地精选词库。本次没有部署公网后台，也没有自动支付功能。

新闻下载及热词更新不包含输入文本、按键、选词历史或音频。所有打字查询仍在本机执行，更新过程在托盘进程异步运行；离线时输入、个人词库、英文补全仍可用。

升级后请关闭并重新打开 TRAE、微信等已有窗口，让它们加载新版 TSF DLL。Android 0.1.2 同步加入本地英文补全、双语热词和主动开启的新闻面板，详见 [Android 说明](../android/README.md)。
