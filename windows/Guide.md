# 数萌 AI 输入法 Windows 0.5.0

作者：数萌AI服务器 (winintel)，service@winintel.com

新增本地中英翻译、双语字幕 SRT 导出和会议逐句记录。使用步骤见随安装包提供的 `Meeting-guide.md`。

适用 Windows 10/11 x64。安装时允许管理员权限，安装完成后打开桌面“数萌 AI 输入法”，按 Win + 空格切换到“数萌 AI 输入法”。托盘“萌”图标提供设置、文字复制和退出。

## 打字

输入 nihao，空格选择“你好”；zg 对应“中国”；nihoa 可纠正相邻字母颠倒。支持全拼、简拼、词频学习和英文词库。数字 1–9 选词，上下键切换候选，Esc 取消。候选词显示在数萌自己的窗口中。切换输入法进入英文直输。

每页显示 9 个候选。PageDown（或 =）下一页，PageUp（或 -）上一页；也可点击候选窗口底部左右两侧，或滚动鼠标滚轮翻页。数字 1–9 选择当前页对应的词，空格或回车选择高亮词。窗口底部显示当前页/总页数。上、下键连续移动时也会跨页。候选列表只显示当前页，后续候选保留在本地列表中。

候选词成功输入后，会记住本次输入和选中的词。例如输入 shi 后按 3 选中第三个词，下次输入 shi，该词优先排到第一。若后来选了另一个词，优先顺序随新的选择更新。记忆仅匹配相同输入，全拼与简拼分别记录；换程序或重启后仍可使用。已有选择记忆的输入优先使用你的选择，模型推荐不会覆盖它。

学习记录保存在当前 Windows 用户的 `%LOCALAPPDATA%\winintel-ime-native\choices-v2.tsv`，旧版 `choices.tsv` 会自动读取并迁移。选择记录不发送到网络；启用可选 API 后，尚无选择记忆的输入仍可能发送当前拼音与候选词。

## 离线语音

技术缩写内部不留空格：`s x m 二` → `SXM2`、`s x m 三` → `SXM3`、`n v link` → `NVLink`。针对 SXM 的字母顺序误识别，`x s m 2` 也规范为 `SXM2`。连续说两次 NVLink 会保留两次。`w i n intel 点 com` → `winintel.com`。只合并已知技术词，不合并任意英文句子。

即使停顿让网址或缩写分成两段识别，草稿合并时也会再次规范化。手动键盘编辑保留原文，撤销可以恢复合并前的草稿。

带宽与数据量分开处理：`56 gigabbs`、`56 Gbit/s` → `56Gbps`；`8 bits` 保留为 `8 bits`；`8 bytes` 保留为 `8 bytes`；明确的 `GBps` 与 `GB/s` 规范为 `GBps`，不改为 `Gbps`。未明确指向已知术语的文字仍可在草稿中编辑。

数字与硬件型号使用阿拉伯数字：`V 一百 三十二 G` → `V100 32G`，`A 一百 八十 GB` → `A100 80GB`。型号与容量之间留一个空格；容量数字与单位紧贴。已知型号连写 `V10032G` 也会分为 `V100 32G`。针对常见 100 系列型号及其容量，修正 V132/V116/A180/A140/H180 连写误差；例如 `V132G` → `V100 32G`，`A180G` → `A100 80G`。这些是有限的型号规则，不是通用未知型号推断。单独的“一百三十二 G”仍为 `132G`，显式 `V100 132G` 也保留实际容量。“一起”“一般”“千万不要”等普通词保留。

转换在本机完成，应用于实时预览、整句复核结果及复核失败回退文字；不需要 API。识别漏掉整个型号或单位时，规则不能恢复录音中不存在于识别文字的内容。

先在数萌设置中选择麦克风，将光标放到需要输入的位置。按 F8 开始，草稿窗口实时显示中英文识别文字；再次按 F8 停止录音，等待整句复核。识别结果保留在草稿中，可直接用键盘编辑，然后点击“确认上屏”，输入到开始录音时的窗口；也可复制到其他位置。再次按 F8 可以继续追加文字或说指令修改现有草稿。

按钮支持清空、撤销、复制和确认上屏。录音中可清空和撤销；停止后可直接编辑草稿和确认。关闭窗口只隐藏，录音仍需按 F8 停止。

| 完整口令 | 草稿操作 |
|---|---|
| 输入法指令，清空 | 清空识别草稿，支持撤销 |
| 输入法指令，撤销 | 恢复上一步草稿 |
| 输入法指令，删除上一句 | 删除最后一句或最后一个完整识别分段 |
| 输入法指令，把明天改成今天 | 将草稿中的“明天”替换为“今天” |

也支持“数萌指令”开头。口令应单独说完整一句，前后稍停顿。普通口述中的“请不要清空这些文字”不会触发清空。指令不编辑其他软件中已输入的文字。

安装包包含 INT8 Zipformer 中英文流式模型和标准 SenseVoiceSmall INT8 整句复核模型，无需另外下载，不依赖云端识别。实时识别和整句复核在两个独立工作线程处理；复核按原分段顺序完成，分段 ID 防止同一结果重复写入，不删除真实重复口述。单段音频最多约 20 秒，复核最多排队四段。麦克风只在按 F8 后打开。Windows 设置 → 隐私和安全性 → 麦克风中，需要允许桌面应用访问麦克风。首次加载模型可能需要数秒。

Voice-accuracy.md 和 Voice-worker.md 给出本机 Windows 合成语音的实测结果；这些测试验证识别链路及口令，不代表真人、方言或噪声环境准确率。

关闭语音预览窗口会隐藏当前预览，识别仍由 F8 结束；下一次录音会重新显示预览。退出数萌时，会取消等待中的模型请求并忽略旧会话的迟到回调。

## 可选开源大模型 API

默认关闭。支持本机、局域网或自行选择的 OpenAI 格式接口，例如本机 Ollama 的 http://127.0.0.1:11434/v1。填写实际模型名称，必要时填写密钥，点击测试连接，再勾选启用并保存。

启用后，尚无个人选择记忆的拼音及当前候选词会发送到所配置的接口，用于候选排序。语音识别及整句复核全部离线，草稿不自动发送到 API。不会发送录音音频或读取应用内其他文字。超时保留本地候选。密钥使用 Windows 当前用户保护机制保存。本软件不提供付费服务，不承诺外部接口永久免费。

## 从源码构建

源码包包含本版本 windows/、复用的 Engine.h、词库编译器、语音传输代码、VoiceSession.cs、ChildJob.cs，以及完整词库数据。安装 Visual Studio 2022 C++ 桌面工具、Windows SDK、NSIS；Windows 自带 .NET Framework 4.x 编译器。

从安装目录取得 models、runtime、node_modules、licenses 作为 AssetRoot，运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\windows\Build.ps1 -AssetRoot "$env:LOCALAPPDATA\Programs\winintel-ime-windows" -Nsis "C:\Program Files (x86)\NSIS\makensis.exe"
```

没有安装包的开发者先运行 windows/AcquireAssets.ps1 获取基础资产，再运行 windows/AcquireSenseVoice.ps1 -AssetRoot "基础资产目录" 获取并校验整句模型，最后将同一目录传给 Build.ps1 的 AssetRoot 参数。

Build.ps1 中的 Visual Studio/SDK 路径需与本机版本对应。资产均为公开开源依赖，固定模型仓库与文件 SHA-256 见 models/voice/model-manifest.json。使用安装目录的资产可完全离线重建，无需付费软件运行时或 API。

选词和分页验证可运行 `windows\Verification\VerifyChoices.ps1 -Payload "安装目录"`。测试编译独立 DLL，创建自己的 TSF 文本框和临时学习记录，不对用户应用发送全局按键。验证详情见 Results.md。
