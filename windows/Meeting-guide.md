# 数萌 AI 输入法 0.5.0：翻译、字幕与会议记录

升级前在旧版数萌托盘菜单点击“退出”，再运行新版安装包，安装完成后打开桌面“数萌 AI 输入法”。

1. 打开数萌设置，点击“翻译 / 字幕 / 会议”，或在托盘右键菜单打开。
2. 在“中英互译”输入文字，选择自动判断、中译英或英译中，点击“翻译文字”。第一次使用某个方向需要加载模型。
3. 会议中按 F8 开始麦克风录音，再按 F8 停止。实时识别显示在语音草稿中；每次停顿、整句复核后，字幕页显示原文和译文。
4. 点击“导出字幕 SRT”保存带时间戳的双语字幕；点击“导出会议记录”保存 Markdown 逐句记录及关键词提取的决策、待办。
5. “新建会议”清空当前字幕；清空前先停止录音并导出需要保留的内容。没有点击导出时，会议记录只在内存中，退出即清除。

翻译使用 OPUS-MT Marian 小型神经机器翻译模型，CPU INT8 推理，并非通用聊天大模型。所有录音、识别和翻译均在本机处理，运行期间禁止自动下载模型。不需要 API 密钥。

术语保护规则保留 DeepSeek、vLLM、Windows、NVLink、CPU、GPU、型号、已知单位和货币身份；优先采用保留了这些事实的完整译文，缺失或改写术语时按原文术语边界分段翻译。该策略优先保留关键事实，但可能使句子衔接不自然，仍需核对译文。

字幕时间对应录音分段，包含该段的停顿，不能当作逐字对齐。多次录音按上一段结束时间续接，暂停期间不计入字幕时间。当前采集麦克风；视频和远程会议的电脑声音需要使用已有的立体声混音或虚拟音频输入设备，不自动抓取系统声音。

自动判断方向：包含中文的段落按中译英处理，全英文按英译中处理。中英混说建议手动选择目标方向。译文没有替换语音输入草稿；会议记录与草稿编辑独立保存，修改草稿不会重写既有字幕。

“决策与待办”是逐句关键词摘录，不是大模型摘要，也不自动识别发言人。专业型号、否定句、金额日期和负责人请核对；可保存文件后编辑。

源码重建：按 `windows/Build.ps1` 准备 Windows SDK、MSVC、.NET Framework 和 NSIS；使用项目 `package-lock.json` 安装依赖。`models/translation/opus-mt-zh-en` 和 `opus-mt-en-zh` 各包含 config、tokenizer、generation_config、special_tokens_map 及 `onnx/encoder_model_quantized.onnx`、`onnx/decoder_model_merged_quantized.onnx`。模型来自 Xenova 同名 Hugging Face 仓库，SHA-256 见 `windows/Legal/Translation-notice.md`。将运行时、词库和模型准备到 AssetRoot，再运行 Build.ps1；源代码包不重复包含模型权重，离线安装包已包含全部运行资产。
