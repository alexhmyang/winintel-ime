# Windows 0.4.2 更新

- 加入 SXM2/SXM3/SXM4/SXM5、NVLink 和 winintel.com 的拆字母规范化。
- 保留 V100 32G 中型号与容量间的空格，连续重复 NVLink 不删除。
- 识别文字中的 gigabbs/gigabps/Gbit/s 规范为 Gbps，bits 与 bytes 分开保留。
- 45 项规则验证通过，包含词边界保护和重复转换稳定性。
- 根据合成音频中的实际输出，补充 envy link → NVLink、winintel com → winintel.com。
- 支持草稿合并停顿分段后拼接已知缩写与网址，保留撤销、重复口述和手动编辑；20 项草稿验证通过。
- 合成语音完整链路中 SXM3、NVLink 与网址验证通过；8 bits 样本漏掉数字，详见 Voice-acronym-draft.md。

## Windows 0.4.1 更新

- 中文数量转换为阿拉伯数字，容量单位规范化为 G/GB/TB 等。
- 型号和容量保留空格：V100 32G、A100 80GB；修复 V10032G 连写。
- 根据常见型号容量修复 V132G → V100 32G、A180G → A100 80G 等，单独的 132G 以及明确的 V100 132G 保留。
- 30 项规则验证通过，包含普通中文词保护和重复规范化稳定性。

## Windows 0.4.0 更新

- 新增标准 SenseVoiceSmall INT8 离线整句复核；Zipformer 使用束搜索和品牌、指令热词。
- F8 停止后保留可编辑草稿；清空、撤销、复制、确认上屏按钮。
- 支持“输入法指令，清空 / 撤销 / 删除上一句 / 把明天改成今天”。
- 独立线程复核、有界音频缓冲、分段 ID 防重复、旧会话迟到回调保护。
- 合成音频实测见 Voice-accuracy.md 和 Voice-worker.md，不代表真人准确率。

## 0.3.2 候选功能（保留）

- 候选结果不再截断到 9 个；每页显示 9 个，显示页码。
- PageDown / = 下一页，PageUp / - 上一页；支持点击候选窗口底部和鼠标滚轮。
- 数字 1–9 选择当前页对应词，上下键连续移动可跨页，空格或回车选择高亮词。
- 相同输入优先推荐最近成功选中的词；个人记录本地持久化，其他应用与重启后仍可加载。
- 原子替换学习文件并同步多进程写入；自动导入旧 choices.tsv。
- 有个人选择记录时，模型排序不会覆盖该输入的个人顺序。

安装后重新打开使用输入法的应用，使其加载新版候选模块。本版本保留 0.3.1 的语音预览生命周期修复。
