# 数萌 AI 输入法 0.5.4

单独按下并松开 Shift，立即切换中英文。英文模式的字母直接交给正在输入的应用，大小写、空格与标点遵循应用的正常行为。长按 Shift 只切换一次；Shift 配合字母、Ctrl、Alt、方向键等组合使用时不切换语言。

切换时会先保留尚未上屏的字母。例如输入 `nihao` 后按 Shift，会保留 `nihao` 并进入英文模式。手动选择的中文或英文模式保持固定，智能判断不会把它改回。

初始为智能模式：明确的常见英文词、技术名称、网址优先保留英文，中文拼音仍显示中文候选。短串可能同时属于英文和拼音；此时按 Shift 明确选择语言。工具栏语言按钮可直接切换；Ctrl + 点击语言按钮恢复智能模式。

左键点击托盘图标打开工具栏；右键打开工具箱，点击“实时语音翻译”。按 F8 或窗口中的录音按钮开始说话，再按一次停止。自动判断、中译英、英译中三个方向可以随时选择。

讲话过程中显示识别文字和临时译文。停顿后生成整句结果，并自动更新双语字幕。临时识别每 650 毫秒取最新文字；待处理临时译文只保留最新一条，避免旧文字不断积压。临时译文会随识别变化，以停顿后的整句结果为准。

“字幕与会议”页保留分段时间、原文和译文，可导出 SRT 字幕及 Markdown 会议记录。语音输入仍保留草稿确认流程：停止录音后可编辑，确认后才输入到目标应用。

候选排序、中英判断、语音识别和翻译在本机 CPU 上运行，不调用付费服务。选词历史保留在本机；音频不上传。
