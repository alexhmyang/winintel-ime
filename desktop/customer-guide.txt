数萌AI输入法 0.1.0 Windows 测试版
品牌：winintel AI | https://winintel.com
源码与反馈：https://github.com/alexhmyang/winintel-ime

安装
1. 双击 winintel-AI-Input-Setup-0.1.0.exe，按安装向导操作。
2. 保持勾选“注册 Windows 系统输入法”。首次安装时允许 Windows 管理员授权。
3. 安装完成启动数萌AI，右下角会出现“萌”托盘图标。
4. 按 Win + 空格，选择“小狼毫”。按 Ctrl + ` 打开方案菜单，选择“数萌AI输入法”。
5. 输入拼音，空格选首选，数字键选词；Shift 切换英文直输。
   中文模式下也支持英文词汇补全。已有小狼毫用户的原方案会保留。

语音
1. 在记事本、聊天软件或文档中，先点击要输入的文本框。
2. 按 F8 开始说话；右下角浮窗实时显示识别文字。
3. 再按 F8 完成。识别句子会自动输入原文本框。
4. 若录音期间切换了文本框，文字保存在托盘“设置与识别记录”里。
5. 在 Windows 隐私设置允许桌面应用访问麦克风。
   F8 若被其他软件占用，关闭冲突程序后重启数萌AI。
   普通权限程序不能向管理员权限程序自动输入。

设置
双击右下角“萌”图标，可以设置登录启动、查看语音记录、修复系统输入法。
关闭设置窗口会继续在托盘运行；退出请使用托盘菜单。

本地大模型
安装包包含离线中英文语音识别模型、完整词库与运行环境。
键盘联想和基础纠错不需要联网。
若要启用大模型候选排序，先另行安装 Ollama，并下载所需模型，
例如 qwen3:0.6b，然后在数萌设置中勾选本地大模型排序并保存。
大模型仅访问本机 Ollama；超时自动采用本地候选。

系统要求与版本
Windows 10 / 11 x64，建议至少 4GB 内存、1GB 可用磁盘。
本版本使用 Rime / 小狼毫作为 Windows 系统输入宿主，系统语言栏显示“小狼毫”。
程序尚未进行商业代码签名，Windows 可能显示未知发布者。
这是可安装的首版测试包，尚无与搜狗同条件的输入准确率或速度对比结论。
卸载数萌会保留用户词频、语音记录以外的设置、Rime 方案和备份；
小狼毫宿主可在 Windows 应用列表中单独卸载。
语音记录只保留在运行内存中，退出后清除。
